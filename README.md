# 99.co Homepage Automation

This project is for testing the homepage UI of the 99.co Android app using Appium and WebdriverIO.

## Tools
- JavaScript
- Appium
- WebdriverIO
- Cucumber
- Android Emulator

## Test
The test opens the 99.co app and saves the homepage UI hierarchy to an XML file.

## Run the test
1. Start Appium:
   `npx appium`
2. Run the test:
   `npx wdio run wdio.conf.js`

The test result and captured UI are saved in the project folder.
